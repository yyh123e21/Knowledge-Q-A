- [x] 1.1 创建 `chunking.py`，实现 markdown 提取适配器：包装库的 `_convert_to_markdown`，导入失败时回退到 `_fallback_text_reader`。验证方式：对一份 PDF 与一份 .md 各调用一次，均返回非空字符串
- [x] 1.2 为提取结果加缓存，键为 `(file_path, mtime, size)`。验证方式：对同一文件连续调用两次，第二次不触发实际转换（用计时或计数断言）
- [x] 1.3 定义 chunk 内部契约与 `materialize(chunks, file_path, namespace, strategy, params)`：产出含 `id` / `content` / `metadata` 的入库 dict，`metadata` 复刻 `source_path`、`file_ext`、`doc_id`、`lang`、`start`、`end`、`content_hash`、`namespace`、`source`、`external`、`heading_path`、`format` 各键，并额外写入 `split_strategy` 与 `split_params`。验证方式：断言产出 dict 的键集合与库 `load_and_chunk_texts` 产出的键集合一致，且 `start`/`end` 满足 `markdown[start:end] == content`
- [x] 1.4 实现策略注册表：策略名 → `{splitter, param_spec}`，`param_spec` 描述每个参数控件的名称、类型、范围、默认值与单位。验证方式：断言三种策略均已注册，且每项 `param_spec` 可被 UI 直接消费（字段完整）
- [x] 1.5 实现 token 计数辅助，复用与库 `_approx_token_len` 相同的口径（CJK 按字、非 CJK 按空白分词）。验证方式：对一段中英混排文本断言计数结果与库函数一致

## 2. 段落分割与 Markdown 结构感知

- [x] 2.1 实现段落分割切分器：以空行段落为单元聚合，受最大块大小与重叠参数约束。验证方式：对一份多段落文档断言 chunk 边界与段落边界对齐
- [x] 2.2 为段落分割加最大块兜底，超长段落在句末标点处继续拆分。验证方式：构造一个超过上限的段落，断言产出的每个 chunk 均不超过上限
- [x] 2.3 实现 Markdown 结构感知切分器：标题层级 + 空行段落聚合，记录 `heading_path`。验证方式：对一份含多级标题的文档断言每个 chunk 的 `heading_path` 与其所属章节一致
- [x] 2.4 断言两个切分器产出的 `start`/`end` 均为原文真实偏移。验证方式：对全部 chunk 断言 `markdown[start:end] == content` 成立

## 3. 语义分割（embedding 驱动）

- [x] 3.1 实现原子单元切分：句子级切分（。！？；+ 换行 + 空行），并将围栏代码块与表格整体视为单个原子。验证方式：对含代码块与表格的文档断言二者均未被从中间切开
- [x] 3.2 实现原子向量化：先做与入库相同的 markdown 预处理，再调用与入库同一个 embedder 批量编码。验证方式：断言所用 embedder 与 `index_chunks` 内部所用为同一来源，且产出向量维度与 Qdrant collection 配置一致
- [x] 3.3 为原子向量加缓存，键为 `(markdown 内容哈希, 原子切分参数)`。验证方式：固定文档连续两次不同敏感度的预览，第二次不触发模型调用（用计数断言）
- [x] 3.4 实现切点判定：计算相邻余弦距离，以 `percentile(d, P)` 为阈值切分，`P` 由敏感度参数给出。验证方式：对同一文档断言敏感度升高时 chunk 数量单调不减
- [x] 3.5 实现尺寸兜底：合并低于最小块大小的 chunk、拆分超过最大块大小的 chunk（后者在句末标点处切）。验证方式：断言产出 chunk 的长度全部落在 `[min, max]` 区间内（文档总长不足 min 时除外）
- [x] 3.6 在 `diagnostics` 中返回切点距离序列与阈值。验证方式：断言序列长度与原子数量匹配，且阈值可由敏感度复现
- [x] 3.7 处理 embedding 不可用的情形：报错并提示改用其他策略，不静默退化。验证方式：停用 embedding 服务后触发语义预览，断言返回明确错误信息且未产出 chunk
